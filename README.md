# HavenCraft — Residential Remodeling Homepage

A responsive, single-page homepage concept for a residential remodeling and construction company.

## Run locally

No build tools or dependencies required. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## What's included
- Premium editorial visual direction: warm ivory, deep charcoal, muted olive and terracotta accents.
- Responsive desktop, tablet and mobile layouts.
- Homepage sections: hero, brand introduction, three core remodeling services, full residential services directory, process, inspiration gallery and enquiry CTA.
- Mobile navigation and a front-end demo enquiry form.
- All listed service categories represented in the homepage content.

## WordPress implementation notes
This concept intentionally uses standard HTML/CSS/JS patterns that can be rebuilt with Elementor or Gutenberg:
- Header and footer: Theme Builder templates.
- Hero, intro, service cards, image/text split and CTA: Containers / Flexbox / Grid.
- Service directory: nested containers and icon/text lists.
- Enquiry form: Elementor Forms, WPForms or Fluent Forms.
- Fonts: Playfair Display for headings; DM Sans / Manrope for body and UI.

Replace the sample brand name, imagery, project claims and contact details with client-approved assets and information before launch. Images currently load from Unsplash URLs and require an internet connection.

## Deploy
Upload the folder to GitHub and import the repository into Vercel. Since this is a static site, no build command is needed and the output directory can remain the project root.
